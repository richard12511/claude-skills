# claude-skills

Personal, user-level [Claude Code](https://claude.com/claude-code) skills, kept in
`~/.claude/skills/` so every project picks them up. This repo versions that directory.

## Skills

| Skill | What it's for |
|-------|---------------|
| [`overnight-qa-loop`](overnight-qa-loop/SKILL.md) | Set up an unattended overnight gnhf loop that drives an app as a real user, finds bugs/UX defects, and fixes them one per iteration. Mine. |
| `axi` · `lavish` · `no-mistakes` | Vendored copies of [kunchenguid](https://github.com/kunchenguid)'s skills, snapshotted here for backup. Source of truth is upstream. |

## Restore on a new machine

```sh
git clone <this-repo> ~/.claude/skills
```
